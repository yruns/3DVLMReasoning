## Project Overview

3DVLMReasoning is a two-stage 3D scene understanding framework: Stage 1
retrieves task-relevant keyframes from a 3D scene graph, Stage 2 runs a
DeepAgents/LangChain v1 ReAct VLM agent that reasons over the retrieved
evidence. Two production benchmarks: **OpenEQA** (open-ended QA, MNAS via
Gemini judge) and **EmbodiedScan VG** (3D visual grounding, 9-DoF IoU).

This session focused on the **EmbodiedScan VG pack** — reorganizing offline
data layout, removing the vDETR detector dependency, and switching to a
GT-pool oracle setting (agent picks an EmbodiedScan instance by `bbox_id`
from the annotation set, no perception step). Concurrently, an in-progress
70-sample real-agent smoke run is verifying the new pipeline.
